# 路线图

## 0.1 服务端和后台骨架

- REST API。
- 分类和题目种子数据。
- SQLite 分表持久化和旧 JSON 自动迁移。
- 静态管理后台。
- 匿名设备 ID 用户状态。

## 0.2 HarmonyOS App MVP

- ArkTS + ArkUI + Stage 工程。
- 首页分类。
- 分类练习、随机练习、错题练习、收藏练习。
- 题目详情与答题反馈。
- 本地缓存、收藏、错题和练习记录。

## 0.3 内容生产闭环

- 管理后台增强。
- 题目审核流程。
- 难度和知识点维护。
- 发布/下架。

## 0.4 面试训练增强

- 基础模拟面试题组。
- 简答题自评记录。
- 后续接入服务端 AI 评分。

## 0.5 可选账号与排行榜

- 保持匿名模式完整可用，不强制登录。
- 已完成服务端华为 Authorization Code 验证和 ArkInterview 会话签发，不自建密码体系。
- 已完成首次登录合并匿名收藏、错题和答题记录。
- 已接入 HarmonyOS Account Kit 客户端、“我的”页面、AssetStore 会话恢复和 Token 自动刷新。
- 已完成登录用户主动开启/关闭排行榜参与设置，默认不参与。
- 已完成周榜、总榜、分类榜接口和 HarmonyOS 排行榜页面。
- 已通过授权时间和作答时资格标记排除匿名历史及退出期间分数，按参与后的每题首次正确计分。
- 客户端 Client ID 已配置；生产 HTTPS、AGC 签名/Redirect URI 配置和真实账号联调待后续恢复该任务时完成。
- 登录用户可选择是否参与周榜、总榜和分类榜。
- 排行榜只统计服务端确认的客观题有效作答。
- 已完成排行榜异常提交频率检测、参与账号分页审计、带原因和内部备注的封禁/解封、可识别操作人和登录会话即时吊销。
- 已完成独立管理员账号、短期会话和超级管理员/题库编辑/排行榜审核三类角色权限。
- 已完成管理员登录失败限流、统一后台操作审计、会话列表和强制下线。
- 产品决定：真实华为账号联调和线上启用暂缓；保留现有实现，匿名模式继续完整可用，登录入口在 HTTPS、正式域名和服务端配置完成前保持禁用。
