# 路线图

## 0.1 服务端和后台骨架

- REST API。
- 分类和题目种子数据。
- SQLite 分表持久化和旧 JSON 自动迁移。
- 静态管理后台。
- 匿名设备 ID 用户状态。

## 0.2 HarmonyOS App MVP

- ArkTS + ArkUI + Stage 工程。
- 首页分类。
- 分类练习、随机练习、错题练习、收藏练习。
- 题目详情与答题反馈。
- 本地缓存、收藏、错题和练习记录。

## 0.3 内容生产闭环

- 管理后台增强。
- 题目审核流程。
- 难度和知识点维护。
- 发布/下架。

## 0.4 面试训练增强

- 基础模拟面试题组。
- 简答题自评记录。
- 后续接入服务端 AI 评分。

## 0.5 可选账号与排行榜

- 保持匿名模式完整可用，不强制登录。
- 已完成服务端华为 Authorization Code 验证和 ArkInterview 会话签发，不自建密码体系。
- 已完成首次登录合并匿名收藏、错题和答题记录。
- 待接入 HarmonyOS Account Kit 客户端和“我的”页面。
- 登录用户可选择是否参与周榜、总榜和分类榜。
- 排行榜只统计服务端确认的客观题有效作答。
